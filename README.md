# 몽글 투두

나 혼자 쓰는 할 일 · 습관 앱. 웹(PC 브라우저)과 안드로이드 앱이 같은 데이터를 써요.

- **할 일**: 날짜별 · 카테고리별 할 일, 하위 할 일, 반복(매일/평일/매주), 알림 시간, 언젠가 할 일, D-day, 기분과 한 줄 일기
- **습관**: 테마와 따로 고를 수 있는 6가지 정원(우주 · 복숭아 과수원 · 토끼 잔디밭 · 구름 하늘 · 병아리 들판 · 벚꽃 꽃밭), 지금 읽는 책 진행률
- **알림**: 할 일 시간 알림, 아침 브리핑, 저녁 체크. 무음 팝업 또는 소리 있는 팝업
- **안드로이드 위젯**: 홈 화면에서 오늘 할 일을 보고 바로 체크
- **설정**: 테마 6종, 체크 모양 4종, 카테고리 색, 24/12시간 표시, 백업과 복원

## 구조

| 위치 | 내용 |
|---|---|
| `src/` | 앱 화면과 로직 (Vite + 순수 JavaScript) |
| `src/config.js` | Firebase 웹 설정값 (비워 두면 이 기기에만 저장하는 모드) |
| `android/` | Capacitor 안드로이드 프로젝트, 위젯(`MongleWidget.java`, `WidgetService.java`) |
| `.github/workflows/build.yml` | 코드를 올리면 웹(GitHub Pages)과 APK(Releases)를 자동으로 만드는 설정 |
| `firestore.rules` | Firestore 보안 규칙 (본인 계정만 읽고 쓰기) |

## 데이터 보안

- 로그인은 Firebase 이메일/비밀번호. 앱에는 회원가입 기능이 없어요.
- Firestore 규칙 때문에 로그인한 본인만 `users/{내 uid}` 아래 데이터를 읽고 쓸 수 있어요.
- `src/config.js`의 값은 원래 공개되는 식별자라 저장소에 있어도 괜찮아요.
- APK 서명 키(`mongle-release.jks`)와 비밀번호는 저장소에 올리지 않아요. GitHub Secrets에만 넣고, 원본은 따로 보관하세요. 키를 잃어버리면 기존 앱 위에 업데이트 설치가 안 돼요.

## 업데이트 흐름

1. 코드를 고쳐서 GitHub `main` 브랜치에 올려요.
2. GitHub Actions가 자동으로 웹을 배포하고 APK를 만들어요 (약 5~8분).
3. 웹: `https://<아이디>.github.io/mongle-todo/` 에 바로 반영돼요.
4. 폰: 저장소의 **Releases**에서 새 APK를 받아 설치하면 기존 앱 위에 업데이트돼요. 데이터는 그대로예요.

## 직접 실행해 보기 (선택)

```bash
npm install
npm run dev            # 브라우저에서 미리보기
# 주소 뒤에 ?local 을 붙이면 로그인 없이 이 기기에만 저장하는 모드로 열려요
```

## 폰에서 처음 설치할 때

1. 폰 브라우저로 저장소의 Releases 페이지에 들어가 `mongle-todo-1.0.x.apk`를 받아요.
2. "출처를 알 수 없는 앱 설치"를 허용해요 (브라우저 또는 내 파일 앱에 대해 한 번).
3. 앱을 열어 로그인하고, **알림** 탭에서 알림을 허용해요.
4. 홈 화면을 길게 누르고 → 위젯 → 몽글 투두를 끌어다 놓아요.
5. 배터리 최적화 때문에 알림이 늦으면: 설정 → 애플리케이션 → 몽글 투두 → 배터리 → 제한 없음.
